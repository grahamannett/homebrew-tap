# Graham's Homebrew tap

Install Aviary with:

```sh
brew install grahamannett/tap/aviary
```

Aviary provides a Bird-compatible CLI for X. This tap installs prebuilt releases for macOS 13+ and Ubuntu 22.04/24.04 or Debian 12, on Apple Silicon/ARM64 and x86_64. No Swift compiler or Python installation is required.

Upgrade with `brew upgrade aviary` and uninstall with `brew uninstall aviary`.

See the [distribution documentation](https://github.com/grahamannett/aviary-swift/blob/main/docs/distribution.md) for authentication, optional `bird` invocation, and the mise alternative.

The formula is generated from the published release's verified `SHA256SUMS`.
